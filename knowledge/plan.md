# 구현과 검증

기존 index.html의 정적 일정 카드 구조를 재사용한다. 새 화면이나 런타임 치환 없이 Day 4 아침 방문을 추가한다.

1. 07:30 시장 방문을 첫 시간표 항목으로 추가하고 기존 08:30 이후 시각은 유지한다.
2. 기존 나고야역 아침 식사를 시장 아침으로 바꾸고 요약·상세 동선을 맞춘다.
3. 기존 검증 스크립트에서 시장 단일 슬롯, 아침 첫 순서, 시각 오름차순, 끼니·상세 일치를 확인한다.
4. node scripts/validate-itinerary.js, HTML 검사, git diff --check와 PR의 Validate itinerary 결과를 확인한다.

Day 3과 공항 도착 시각은 유지한다. 시장과 개별 식당의 휴무·영업 시간 확인 항목을 둔다.

## 둘째 날 아침 반영
기존 정적 슬롯 형식으로 07:30 신파치 쇼쿠도를 추가하고 08:20 카페 이후 시각은 유지한다. 끼니·상세·요약을 맞추고 기존 validator에 중복 및 카페 이전 순서 검사를 추가한다. PR 없이 main에 직접 반영한 뒤 GitHub Pages 배포와 공개 URL을 확인한다.

## 첫날 일정 조정
기존 카드 형식으로 점심을 12:10 나고야역 키시멘으로 대체하고 12:55 출발, 14:00 지브리파크 도착으로 연결한다. 관람은 공식 폐장인 17:00까지, 역 이동 후 17:20 출발, 19:00 야키니쿠 예약, 21:00 야경 순서로 맞춘다. 옛 라멘·시간 잔존과 예약 시각을 validator로 확인하고 main 직접 반영 후 공개 페이지를 검증한다.
